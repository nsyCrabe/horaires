# Mes horaires (PWA)

Stocke tes captures de planning sur ton téléphone et les ouvre en un tap, même hors ligne.

## Mise en ligne sur GitHub Pages
1. Crée un dépôt (ex. `horaires`) et envoie-y tous ces fichiers à la racine :
   `index.html`, `manifest.webmanifest`, `sw.js`, dossier `icons/`.
2. Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Ouvre `https://TON-PSEUDO.github.io/horaires/` sur ton Pixel, dans Chrome.
4. Menu ⋮ > « Installer l'application » (ou « Ajouter à l'écran d'accueil »).

## Utilisation
- « + » : choisis une ou plusieurs captures dans ta galerie.
- Pincer / double tap : zoom. Crayon : renommer. Corbeille : supprimer.
- Une fois installée, l'app apparaît dans le menu « Partager » d'Android :
  partage une capture depuis la galerie ou un mail et elle s'ajoute toute seule.
